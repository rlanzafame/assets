## Image Tests

Here are a couple tests using an image from this repository `./images/sailboat-sloop.svg` that is rendered in the README using GitHub and jsdelvr:

### Using a GitHub Server

URL structure is:

```
https://rlanzafame.github.io/assets/ + FILEPATH
```

![test](https://rlanzafame.github.io/assets/images/sailboat-sloop.svg)

### Using a JSDelivr Server

Use the [JSDelivr site](https://www.jsdelivr.com/github) to create a URL for a file in GitHub. URL structure is:

```
https://cdn.jsdelivr.net/gh/rlanzafame/assets@main/images/ + FILEPATH
```

![test](https://cdn.jsdelivr.net/gh/rlanzafame/assets@main/images/sailboat-sloop.svg)
